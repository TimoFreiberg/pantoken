## Pre-existing flake fixed during verification (mock driver)

The baseline run failed `streaming.e2e.ts` (reply turn stalled). Root cause found with
temporary instrumentation (removed after diagnosis): the `slowabort` script delays
`abort()` by 1000ms, and the stop-turn test "a retried Esc-after-timeout" ends while
that delayed abort is still pending. The delayed abort then called `cancel_timers()`
**unconditionally**, landing in the NEXT test and killing its in-flight script (the
reply's later steps were never fired). Fix: the delayed abort now captures the
generation before its sleep and skips `cancel_timers()` if a reset happened since
(same guard the settle path already had). Also hardened `waitForSettledWorkBlocks`
count/settle assertions to 15s (the count race was a second, rarer full-suite flake)
and the qna "scroll position is independent per page" synchronous scroll reads now
poll (a third flake). All three are documented here per the merge-report convention.
